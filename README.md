# Assignment 3 - Graph Algorithms

Java 17: DSU, Kruskal, Prim, Kosaraju SCC, DFS topological ordering and DAG shortest paths with route reconstruction.

Run from the project folder with JDK 17+ and Python 3.12+:

```powershell
py -3 tools/run.py --input tests/cases.jsonl
py -3 tools/run.py --check
py -3 tests/check.py
```

These commands run the examples, Public checks and own tests with the benchmark, respectively.

In VS Code, open `tests/Check.java` and press Run to see the examples without entering input.
